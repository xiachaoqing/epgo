# xiachaoqing.com AdSense 内容整改记录

日期：2026-11-05

## 本次发现

线上 `ep_news` 曾有 203 篇公开中文文章，其中 163 篇没有编辑审核标记，首页和站点地图会把这些同步文章当作主站内容展示。线上 sitemap 共 223 个 URL，其中约一半属于 `/daily/`，与英语陪跑GO的 KET / PET 学习定位不一致。部分同步稿过短、发布时间集中，容易让网站看起来像公众号内容聚合页。

## 本次处理

- 线上先备份了待处理文章：`/root/epgo_adsense_cleanup_20261105.sql`。
- 将 163 篇没有 `issue` 审核标记、或标记为 `wechat-repaired-20261012` 的文章改为 `recycle=1`。这是可恢复的回收状态，没有物理删除。
- 保留 40 篇带 `原创专题` 或 `editorial-v2` 标记、正文不少于 2000 字节的文章作为当前公开内容。
- 首页只读取上述两类人工审核文章，不再显示“公众号整理”或自动同步文章。
- `/daily/` 不再作为静态 sitemap 页面；每日英语栏目在模板中输出 `noindex,follow`。
- 公众号历史导入脚本改为默认写入 `pending-review` 和隐藏状态。只有明确传入 `--publish-reviewed --issue 原创专题` 或 `--issue editorial-v2` 才会进入公开流程。

## 当前判断

这次解决的是公开内容边界和同步回流问题，不代表 Google 一定通过审核。下一次提交前仍要用 Search Console 检查旧 URL 的抓取状态，并人工抽查保留的 40 篇文章、首页、栏目页、关于我们、隐私政策和服务条款。
