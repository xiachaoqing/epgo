# xiachaoqing.com AdSense 内容整改记录

日期：2026-11-05

## 本次发现

线上 `ep_news` 曾有 203 篇公开中文文章，其中 163 篇没有编辑审核标记，首页和站点地图会把这些同步文章当作主站内容展示。线上 sitemap 共 223 个 URL，其中约一半属于 `/daily/`，与英语陪跑GO的 KET / PET 学习定位不一致。部分同步稿过短、发布时间集中，容易让网站看起来像公众号内容聚合页。

## 本次处理

- 线上先备份了待处理文章：`/root/epgo_adsense_cleanup_20261105.sql`。
- 将 163 篇没有 `issue` 审核标记、或标记为 `wechat-repaired-20261012` 的文章改为 `recycle=1`。这是可恢复的回收状态，没有物理删除。
- 保留 40 篇带 `原创专题` 或 `editorial-v2` 标记、正文不少于 2000 字节的文章作为当前公开内容。
- 首页只读取上述两类人工审核文章，不再显示“公众号整理”或自动同步文章。
- `/daily/` 不再作为静态 sitemap 页面；每日英语栏目在模板中输出 `noindex,follow`。
- 公众号历史导入脚本改为默认写入 `pending-review` 和隐藏状态。只有明确传入 `--publish-reviewed --issue 原创专题` 或 `--issue editorial-v2` 才会进入公开流程。
- 第二轮抽查发现 12 篇文章虽然 HTML 字节数超过 2000，但正文实际只有约 775–936 个中文字符。已逐篇补充自编材料、答案理由、错误分类、复盘任务和适用边界，线上正文长度提升到约 3300–3800 字节；发布前使用 `20261105-quality-upgrade-manifest.json` 做正文哈希校验。
- 文章页增加“按主题继续阅读”入口，连接栏目页、学习工具、关于与编辑说明，避免文章成为孤立落地页。
- 2026-11-06 新增 5 篇网站版原创学习指南，覆盖 PET 阅读匹配、阅读干扰项、写作表达和交卷检查；均以 `editorial-v2` 公开，正文约 2900–3200 字节，公开中文文章从 40 篇增加到 45 篇。
- 同日继续新增 5 篇 KET/PET 词汇、听力和写作指南；更新导入分类规则，使 PET 听力进入 PET 题型栏目。线上公开中文文章达到 50 篇，最短正文约 2136 字节，sitemap 为 69 个 URL（19 个固定页面 + 50 篇文章）。
- 随后补充 5 篇 KET 阅读/真题训练、PET 学习计划/口语和英语演讲指南，覆盖原来数量偏少的栏目。线上公开中文文章达到 55 篇，sitemap 为 74 个 URL（19 个固定页面 + 55 篇文章）。
- sitemap 生成器改为优先使用文章 `updatetime` 作为 `lastmod`，文章重写后的更新时间不再被原始发布日期覆盖。
- 全量检查 sitemap 后移除旧的 `/about1/`，为测评页和工具页补 canonical，并把文章 616 从错误的 about 栏目调整到 PET 综合栏目；线上 sitemap 现有 73 个 URL，全部返回 200、全部有 canonical、无误标 `noindex`。
- 继续补充 5 篇词汇复习、科普阅读、地图听力、亲子阅读和口语纠错指南，公开中文文章达到 60 篇；最新 sitemap 为 78 个 URL，已再次完成全量 HTTP、canonical 和 `noindex` 检查。

## 当前判断

这次解决的是公开内容边界、同步回流、最短文章深度和持续增加原创专题的问题，不代表 Google 一定通过审核。下一次提交前仍要用 Search Console 检查旧 URL 的抓取状态，并人工抽查保留的 60 篇文章、首页、栏目页、关于我们、隐私政策和服务条款。
