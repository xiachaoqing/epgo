- 停止 `daily_maintain_epgo.py` 的自动发文定时任务。后续文章必须经过人工选题、撰写和检查后再发布。
- `ep_news` 原有 305 篇公开文章中，第一轮保留 Cathy 原创专题 15 篇；其余 290 篇改为回收状态，未物理删除，便于复核和恢复。

## 备份和回滚

服务器保存了整改前的完整 `ep_news` 数据备份和整改前的 crontab 备份。回滚前必须先确认要恢复的文章经过版权、原创性和内容质量复核，不要直接全量恢复。

数据库文章下线使用的是 `recycle=1`，不是物理删除。恢复单篇时应先检查标题、正文、作者、来源、图片和版权，再将该条恢复为公开状态，并同步检查站点地图。

## 重新提交前的检查清单

1. 继续人工审核已新增的题型文章，确认示例、步骤和适用边界符合 Cathy 的真实教学经验；后续再按家长问题补充内容，不要恢复旧自动生成文章。第二批新增内容重点覆盖听力填空、语法词汇、作文自改、口语录音、亲子阅读、计划中断和考前安排。
2. 逐页检查首页、栏目页、文章页、关于我们、隐私政策、服务条款和联系方式。
3. 确认所有公开页面能正常访问，旧低质量 URL 不在站点地图中，且返回 404 或不再公开展示。
4. 检查文章作者、发布日期、来源说明和图片授权，不使用虚构数据或虚假用户评价。
5. 检查 AdSense 代码只出现在适合展示广告的内容页，不在支付、测评结果或需要完成任务的交互页面制造误导性点击。
6. 重新提交前等待内容稳定一段时间，并以 Search Console 的抓取结果为准；不能保证审核一定通过。
