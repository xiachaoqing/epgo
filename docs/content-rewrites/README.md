## 发布与恢复

- `20261006-manifest.json` 记录每篇文章的 ID、处理动作及发布前的正文 SHA-256。先运行 `php scripts/apply_article_rewrites.php docs/content-rewrites/20261006-manifest.json` 预检，再加 `--apply` 执行。脚本写入前会锁定并核对所有记录，任何一条发生漂移都整体退出。
- 本次数据库完整发布前备份在服务器 `/root/epgo-editorial-20261006/backup.json`，权限为 `0600`。同目录的 `index.before.php`、`shownews.before.php`、`sitemap.before.xml` 是模板与 sitemap 的发布前副本。原始 `/tmp` 备份可能定期清理，应优先使用 `/root` 下的副本。
- 六篇 HTML 修订稿和执行脚本在服务器 `/root/epgo-editorial-20261006/` 留有副本；发布后已从公开网站目录移走，避免形成可索引的重复网页。
- 若要恢复单篇，先核对该备份里的 `id` 与当前数据库记录，再恢复相应字段，勿直接整库覆盖后续新增文章。下架文章恢复时还需同步 sitemap 和重新核稿。
- 本地代码仓库包含六篇新正文、清单、发布脚本和 sitemap 更新脚本；数据库正文与代码是两套状态，Git 推送不等于数据库发布。
