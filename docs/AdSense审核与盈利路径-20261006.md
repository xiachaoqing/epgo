# 英语陪跑GO：审核与盈利路径

## 内容定位

网站只围绕孩子和家长能实际遇到的 KET/PET 学习问题写：题型理解、错题复盘、家庭练习、学习计划和级别选择。每篇文章遵循：明确问题和适用人群；给出英语陪跑GO自己的判断方法；放自编材料、练习和答案理由；说明适用边界和“不是官方真题/成绩承诺”；最后引导下一步学习，而不是把正文写成广告。

可以参考热门搜索问题确定选题，但不抓取、翻译或改写其他网站的整篇文章。Google 的审核重点是原创价值、清晰导航、完整站点和良好用户体验，文章数量与随机日期不能替代这些条件。

## 建议的文章栏目

- KET/PET 题型方法：阅读定位、听力记录、写作展开、口语表达；
- 家庭学习执行：15 分钟练习、熏听、复盘、学习中断；
- 家长决策：KET/PET 选择、测评结果解读、考试前安排；
- 学习证据：录音、短文、错题表和两周前后对比；
- 资源使用说明：哪些材料适合什么阶段，如何遵守版权。

避免泛科技、无关工具、复制资讯、没有答案的题库页和只为放广告而写的短页面。

## 收入路径

### 1. AdSense 辅助收入

先让文章通过搜索解决问题，再在文章正文之间或正文末尾放少量广告。测评、上传、支付、账号查询和工具操作页不应被广告遮挡。AdSense 收入取决于真实访问量、用户地区、广告需求和页面体验，不能按文章数量直接估算。

### 2. 免费测评到人工解读

文章和测评保持免费，用户完成测评后留下联系方式或关注公众号。收费项目可以是一次人工报告：四项能力说明、主要错误、14 天计划和一次答疑。报告必须根据真实答案生成，不能承诺考试通过。

### 3. 三个月熏听/伴读计划

把现有线下服务沉淀为线上交付：材料清单、每周任务、录音提交、老师反馈和阶段复盘。价格、服务周期和人工反馈次数要在购买页写清楚，App 只负责学习记录，不能把打卡次数包装成效果。

### 4. 英语陪跑GO App 服务

测评和文章解决“我该从哪里开始”，App 解决“每天做什么、如何提交和如何反馈”。购买后人工开通的限制要在页面说明，保持现有支付和履约流程不变。

### 5. 线下课与线上服务组合

线下课提供讲解和互动，线上计划提供课后执行，App 保存证据。先用现有 30 名学生验证续费率、任务完成率和老师每周实际耗时，再决定是否扩大招生。

## 审核前检查

- 首页、文章、关于我们、隐私政策、服务条款和联系我们都能访问；
- sitemap 只包含公开且有内容的文章；
- 下架文章不在 sitemap 和首页推荐中；
- 文章作者、内容来源和自编示例说明一致；
- 不购买虚假流量、不设置诱导点击广告的文字、不把广告放在空工具页；
- 通过 Search Console 检查抓取和索引后，再提交 AdSense 审核。

Google 最终是否通过只能由其后台审核决定。本计划能减少低价值、复制和站点不完整风险，不能保证审核结果。
