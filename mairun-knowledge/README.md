# 麦润工业电气知识库原型

这是 `tech.mairunkeji.com` 的独立静态原型，不会自动接入现有麦润宣传站，也不会触碰英语陪跑 Go 的购买、支付和账号流程。

## 本地预览

```bash
cd mairun-knowledge
python3 -m http.server 8080
```

打开 `http://127.0.0.1:8080/`。

## 上线前

1. DNS 增加 `tech.mairunkeji.com` 的 A 记录。
2. 在服务器建立独立目录和 Nginx 配置，并申请覆盖该子域的 SSL 证书。
3. 继续补充人工审核的原创文章，确认图片、参数和引用均有授权或来自自有资料。
4. 内容达到上线门槛后再接入 AdSense，不把广告放进下载按钮、询盘按钮或容易误点的位置。

原型里的产品入口只是“技术咨询”占位链接，部署前应替换为真实询盘地址。
